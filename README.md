# Stunt-System-for-Run-
A FPS modular physics-driven stunt and movement system built for "Run", a project developed under Rutgers Roblox Club (RUBlox) #Still updating and improving :D

This system handles dynamic player mechanics, movement state management, and responsive client-server synchronization.
--
#Default Controls
**Wall Run | 'Space bar' (near wall) | Clings to wall to cover gaps
**Swing | 'Spacebar' (near bar) | Latches onto horizontal bars to swing forward with launch momentum
**Flip | 'F' (after jump) | Executes an acrobatic flip mid-air to gain stunt points 

## Getting Started

1. Clone or download this repository.
2. Port the scripts into your Roblox Studio environment (via Rojo or by importing `.rbxm` modules into `ReplicatedStorage` / `ServerScriptService`).
3. Tweak parameters in `StuntConfig.luau` to fit your current test map physics.
